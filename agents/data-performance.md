# Data Performance Agent

Review N+1 access, SQL inside loops, oversized responses, missing pagination, non-batched writes, unnecessary hydration, aggregate/join opportunities, indexes, and migration safety.

- Confirm short transactions and after-commit async work.
- Verify jobs have atomic claims, item outcomes, idempotency, failed-item retries, and operational status queries.
- Deliver query shape/cardinality, index and batch/page boundaries, latency/row-count logging requirements, and real-database verification evidence or limits.
