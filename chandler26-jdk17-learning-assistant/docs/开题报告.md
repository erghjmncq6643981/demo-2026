# 1、本选题的意义及国内外发展状况：
## 1.1 选题背景及意义
随着互联网、移动终端和人工智能技术的发展，在线英语学习已经由传统的电子词典、固定课程资源逐步向智能化、个性化和交互式学习方向发展。2022 年底，ChatGPT 的发布推动大语言模型进入公众视野。此后，DeepSeek、通义千问、Kimi、豆包、混元等国产大语言模型快速发展，使人工智能在文本理解、内容生成、知识问答和语言学习等场景中的应用具备了较好的技术基础。

传统英语词汇学习工具主要依赖预先整理的词库和固定学习内容，虽然具有较高的稳定性，但难以根据学习者的实际需求动态生成例句、搭配、记忆提示及语境化文章。通用型大语言模型能够生成丰富的英语学习内容，但直接使用通用聊天工具仍存在生成结果格式不统一、内容难以长期保存、无法结合个人学习进度安排复习、重复调用成本较高以及用户数据安全难以保障等问题。

因此，本课题拟设计并实现一个基于大模型的英语学习助手，将大语言模型的内容生成能力与单词本管理、学习笔记、间隔重复、文章学习和学习记录等功能相结合，形成“词汇查询与生成、加入个人单词本、制定复习计划、跟敲练习、文章语境学习”的完整学习闭环。

本课题的研究意义主要体现在以下几个方面：

+ 第一，具有一定的教育应用意义。系统利用大语言模型生成词义、音标、双语例句、固定搭配、相关词和记忆提示，并将单词进一步组织到文章语境中，有助于学习者从孤立记忆转向语境化理解，提高词汇学习内容的丰富性。
+ 第二，具有个性化学习意义。系统根据用户的单词本、掌握状态和复习结果安排后续复习，并保存用户笔记和个人词汇卡快照，使学习内容能够围绕个人进度持续积累。
+ 第三，具有工程实践意义。课题将研究大模型结构化输出、多模型兼容、Prompt 模板管理、学习内容缓存、个人数据快照以及模型密钥加密存储等问题，为大语言模型在垂直学习系统中的工程化应用提供实践参考。
+ 第四，具有一定的应用价值。系统能够减少学习者在词典、聊天工具、笔记软件和复习软件之间反复切换的问题，将内容生成、知识管理和重复学习集中在同一平台中，提高英语学习过程的连续性和可管理性。

## 1.2 国外发展状况
国外计算机辅助语言学习研究起步较早，已经经历了数字化教学资源、在线课程、移动学习和智能学习等多个发展阶段。Anki 等工具采用间隔重复机制安排记忆内容；Quizlet 提供电子词卡、测试和学习活动；Duolingo 等语言学习平台通过任务化设计、学习数据分析和自适应练习提高用户参与度。这些产品表明，词汇卡片、重复记忆、即时反馈和学习进度管理已经成为数字语言学习的重要组成部分。

近年来，生成式人工智能开始被应用于语言学习领域。大语言模型可以根据学习者输入生成例句、对话、语法解释、阅读材料和练习题，并提供较为自然的交互体验。相关研究逐渐从一般问答转向智能辅导、个性化内容生成、写作反馈和口语训练等应用方向。

但是，现有研究和产品仍面临一些问题：一是大语言模型可能产生事实错误或不符合学习目标的内容；二是通用聊天内容通常缺少统一的数据结构，不利于后续检索和复习；三是学习内容、用户状态和复习计划之间缺少持续关联；四是模型调用成本、用户隐私和数据安全仍需进一步研究。因此，将大模型与结构化数据管理、间隔重复和学习过程记录结合，已成为智能教育应用的重要发展方向。

### 1.3 国内发展状况
国内在线英语学习产品发展较快，百词斩、扇贝单词、不背单词、有道词典等产品已经形成较成熟的词汇学习模式，能够提供词义、例句、发音、单词本和复习计划等功能。国内高校和研究机构也持续开展计算机辅助英语教学、移动学习、智能推荐和生成式人工智能教育应用等方面的研究。

随着 DeepSeek、通义千问、Kimi、豆包等国产大语言模型的发展，国内英语学习应用开始尝试引入智能问答、作文批改、口语陪练和学习材料生成等功能。生成式人工智能在降低内容制作成本、丰富学习语境和提供个性化反馈方面表现出较大的应用潜力。

然而，国内现有产品通常存在两种情况：一类以固定词库和既定学习流程为主，内容稳定但个性化生成能力有限；另一类以通用 AI 对话为主，能够生成内容但缺少单词本、复习调度和长期学习数据沉淀。部分系统还存在仅支持单一模型、AI 输出难以结构化、重复调用成本较高、模型密钥保护不足以及学习记录无法跨场景复用等问题。

综上，国内外英语学习系统正在向智能化、个性化和生成式学习方向发展，但如何将大模型生成能力与个人知识管理、科学复习机制和数据安全体系有效结合，仍具有研究与实践价值。本课题将在现有研究和产品基础上，重点探索多模型接入、结构化词汇卡、公共缓存与个人快照分离、间隔重复以及文章语境学习等功能的综合实现。

## 二、本课题的研究内容（论文撰写提纲）
## 2.1 主要研究内容
本课题以个人英语词汇学习为主要应用场景，采用前后端分离架构，设计并实现一个基于大模型的英语学习助手。主要研究内容如下：

1. 研究系统的用户需求、功能需求和非功能需求，分析词汇学习、文章学习、单词本管理、复习计划和模型管理等业务流程。
2. 设计支持 OpenAI-compatible 接口的多模型接入方案，实现模型供应商配置、模型切换、Agent 管理、Prompt 模板管理、会话复用及调用记录保存。
3. 研究大模型输出的结构化处理方法，通过 Prompt 约束模型生成包含词义、音标、例句、搭配、相关词和记忆提示等内容的 JSON 数据，并对输出结果进行解析、校验和持久化。
4. 设计词汇学习缓存机制。对用户输入的词汇进行归一化处理，同一词汇优先读取公共缓存，减少重复调用；同时支持基于编辑距离的拼写容错和最佳匹配。
5. 设计公共词汇缓存与个人单词本快照分离机制。用户将词汇加入单词本时保存个人学习卡快照，避免公共缓存被重新生成后覆盖用户已有的学习内容、笔记和复习进度。
6. 实现文章学习功能。用户可从单词本选择词汇并设置文章长度、难度和学习要求，由大模型生成英文文章、中文译文、词汇用法、语法知识、练习题和学习建议，并保存历史记录。
7. 实现单词本和复习模块，包括多单词本管理、熟练状态管理、共享学习笔记、字母跟敲练习、复习结果记录以及基于间隔重复思想的下次复习时间计算。
8. 设计系统安全机制，使用 Spring Security 和 JWT 实现身份认证与接口访问控制，使用 AES-GCM 对模型 API Key 进行加密存储，并记录重要业务操作和异常日志。
9. 对系统进行功能、接口、安全、性能和兼容性测试，验证系统是否满足任务书规定的主要技术指标。

# 3、研究方法、手段及步骤（进度计划）:
## 3.1 研究方法
1. **文献研究法**：查阅大语言模型、生成式人工智能辅助教学、英语词汇学习、间隔重复、个性化学习和软件系统设计等方面的资料，为需求分析和系统设计提供理论依据。
2. **调查与需求分析法**：结合个人英语学习需求以及现有英语学习产品的功能，分析用户在查词、知识整理、复习和文章阅读过程中的主要问题，明确系统功能边界。
3. **对比分析法**：对比传统词汇学习工具、通用 AI 对话工具和本系统的功能特点，分析固定词库与动态生成、多模型与单模型、公共缓存与个人数据之间的差异。
4. **软件工程方法**：按照需求分析、总体设计、详细设计、编码实现、系统测试和部署验收的过程开展研究，使用用例图、流程图、数据库关系模型和接口文档描述系统。
5. **原型迭代法**：先完成核心学习流程原型，再根据实际使用情况逐步完善词汇卡片、文章学习、复习交互和模型管理功能。
6. **实验测试法**：通过功能测试、接口测试、异常测试、安全测试和性能测试，对缓存命中率、AI 响应时间、并发能力、页面加载时间及拼写容错等指标进行验证。

## 3.2 技术手段与实施步骤
系统采用前后端分离架构。后端基于 Java 17、Spring Boot、Spring Security、JWT、MyBatis-Plus 和 MySQL 实现业务逻辑、身份认证及数据持久化；前端采用 HTML、CSS 和模块化 JavaScript 实现学习界面；AI 部分通过 OpenAI-compatible 接口接入多家大模型。
