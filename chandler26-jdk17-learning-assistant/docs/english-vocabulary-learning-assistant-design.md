# 英语词汇学习助手已实现功能说明

> 本文只说明当前前后端已经实现并可使用的功能。方案讨论、未实现规划、完整接口清单和数据库字段定义不在本文重复记录。

## 1. 产品定位

英语词汇学习助手面向自考英语、四级、六级、雅思及个人英语学习场景，将公共词表、个人学习计划、场景学习、词汇检查和复习记录串成完整闭环。

产品重点解决三个问题：

- 将数千词的公共词表拆分为可执行的场景学习单元。
- 用文章和相关词群建立语境，降低孤立背词的理解成本。
- 按“认识”或“会拼写”的目标检查每个单词，并持续记录学习结果。

## 2. 产品结构

| 功能区 | 已实现能力 |
| --- | --- |
| 个人信息 | 账户、单词本管理、学习计划、Agent 管理、系统日志、AI 会话 |
| 单词本 | 个人词条列表、状态筛选、学习卡详情、笔记和文章学习 |
| 词汇大挑战 | 学习计划选择、周/月日历、场景预览、场景学习和词汇挑战 |
| 卡片学习 | AI 查词、结构化词卡、发音、加入单词本 |
| 文章学习 | 从个人单词本选词生成文章并保存历史记录 |
| 复习 | 跟敲、例句回顾、记忆结果提交和下次复习安排 |

## 3. 核心学习闭环

公共词表导入发布 -> 创建个人学习计划 -> AI 规划场景和掌握要求 -> 学习场景文章及相关词 -> 完成词汇检查 -> 保存逐词记录 -> 进入后续复习。

学习者也可以从卡片学习直接查词，将词卡加入个人单词本，再通过文章学习或复习继续使用这些词汇。

## 4. 已实现功能

### 4.1 账户与个人工作台

- 支持注册、登录、退出登录和 Spring Security + JWT 鉴权。
- 支持修改昵称和密码。
- 展示单词本数、单词数、待复习数和学习活跃图。
- 个人信息页集中管理单词本、学习计划、AI Agent、系统日志和 AI 原始返回。

### 4.2 单词本与公共词表

- 新建的单词本属于当前用户，用于保存个人词汇和学习状态。
- 公共词表通过“个人信息 -> 单词本管理”导入，支持自考、四级、六级和雅思数据源类型。
- 支持 Markdown 表格导入，并按表头识别序号、单词、音标和释义。
- 导入结果支持筛选全部疑似断词、逐条手工修改和批量采用修正建议。
- 审核完成后可发布为公共词表，供学习计划选择。
- 个人单词本支持按熟悉、模糊、遗忘筛选，查看词卡详情、编辑 Markdown 笔记、修改状态和删除词条。
- 单词加入个人单词本时保存词卡快照，公共缓存后续更新不会覆盖个人学习内容。

### 4.3 学习计划

- 在“个人信息 -> 学习计划”中新建和编辑个人计划。
- 计划包含名称、学习目标、公共词表、开始时间和结束时间。
- 学习目标用于帮助 AI 判断词汇需要达到“认识”还是“会拼写”。
- 支持未开始、学习中、暂停、完成和取消等计划状态。
- 后端不限制每日场景数和每日拼写词数量，学习者可按实际进度推进。

### 4.4 词汇大挑战

- 可选择个人学习计划，并查看该计划的学习进度和场景列表。
- 日历默认显示本周完整自然周，只保留周、月两种视角。
- 支持上一周或月、下一周或月、回到本周；月视图显示完整月份网格。
- 过去日期仍可显示和点击，日期和场景均可预览待挑战词汇。
- 日历展示真实待挑战数量、已完成状态和逾期数量；未生成日期展示预计学习量。
- 当前场景未完成时也可以提前生成后续场景，生成后不会强制切换当前学习内容。
- 场景学习包含英文文章、中文译文、核心词汇和更多场景相关词汇。
- 初次学习且大概率不认识的词在文章中显示音标和当前语境含义。
- 场景相关词支持按层级和关键词筛选，并可将扩展词提升为核心词。
- “词汇挑战”先只展示本场景需要学习的单词，再由学习者主动开始检查。

### 4.5 词汇检查与学习记录

- 所有核心词先完成四选一含义检查。
- 要求“会拼写”的词还需完成跟敲单词和根据含义拼写。
- 每个单词分别记录检查阶段、正确与错误次数、得分、掌握状态和下次复习时间。
- 完成场景后保留学习记录，并可继续生成或选择其他场景。

### 4.6 AI 词卡与卡片学习

- 输入单词或短语后，AI 生成结构化词卡。
- 词卡包含释义、英美音标、双语例句、搭配及含义、同义词、反义词、词族和记忆提示。
- 同义词、反义词和词族展示为相关词；搭配保留在独立区域。
- 公共词卡按归一化词条缓存，普通查询优先复用缓存。
- 场景生成后先过滤不需要词卡和已命中缓存的词，仅将缺失词按批次交给 AI 生成，并支持失败项重试。
- 支持单词、音标、例句和搭配发音。

### 4.7 文章学习

- 从个人单词本选择词汇，可按掌握状态和前缀筛选。
- 支持设置文章字数范围、难度和补充要求。
- AI 返回英文文章、中文译文、词汇用法、语法点、重点知识、练习题和学习建议。
- 文章和译文采用便于对照阅读的形式展示。
- 生成结果保存为个人历史记录，相同条件优先复用已有结果。

### 4.8 复习

- 选择单词本和数量后直接进入复习卡片。
- 支持键盘跟敲，输入错误时提供视觉和声音反馈。
- 跟敲完成后展示双语例句并支持朗读。
- 学习者提交忘记、模糊或记住，系统更新掌握度、复习阶段和下次复习时间。
- 选择忘记时立即展示词卡核心内容；选择记住时自动进入下一个单词。
- 学习页与复习页共用同一份个人 Markdown 笔记。

## 5. AI 与系统支持

- 支持维护 OpenAI-compatible 模型配置、学习 Agent 和 Prompt 模板。
- 模型 API Key 由后端使用 AES-GCM 加密保存，前端只显示脱敏值。
- Prompt 模板保存前校验 {{term}} 等必需占位符。
- 词卡、文章、场景、掌握要求和批量词卡等 AI 调用场景已统一枚举，便于独立校验返回结构。
- 同一用户在同一学习场景中复用 AI 会话，避免每次请求创建新会话。
- 重要业务操作写入服务端日志和系统日志，可在个人信息页查看。
- 前端提供 preview=1 Mock 模式，在本机没有数据库时可体验主要产品流程。

## 6. 数据与业务边界

- 公共词表供所有学习计划选择，个人单词本、学习计划、笔记和学习记录仅属于当前用户。
- AI 生成词卡是共享缓存；加入单词本后的词卡快照和学习状态属于个人数据。
- 场景扩展词用于建立主题认知，只有核心词进入当前场景的强制检查。
- 学习进度以场景单元推进，不使用后端每日数量上限限制学习者。
- 所有需要登录的业务接口均校验 JWT 和数据归属关系。
